# StudyOS feature import

## Rules

1. Import each feature into DeepTutor's own pages and navigation under `web/app/(workspace)`. Use the existing workspace shell and keep the experience in the same app.
2. Keep study data in the fork's own storage. Add no MongoDB, Firebase, or other service.
3. Preserve StudyOS attribution and applicable licence notices for any code reused.
4. Cut one ticket per feature. Each ticket ends with a screen a person can open from the workspace.
